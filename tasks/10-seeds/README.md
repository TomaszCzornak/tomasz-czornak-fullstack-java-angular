# Seeds

Stwórz branch na bazie gałęzi main: `git checkout -b feature/seeds main`

## Opis

Zaimplementuj logikę seedowania bazy danych.

Oznacza to, że za pomocą jakiejś komendy powinieneś móc
wypełnić bazę danych wstępnymi danymi:

- użytkownikami
- ofertami pracy
- kandydatami

## Nice to have

- Wykorzystaj narzędzie generujące dane takie jak dane personalne, maile, hasła itd.
- Wykorzystując te narzędzie stwórz dużą ilość danych podczas seedowania.

## Pre code review checklist

W folderze `/tasks/pre-code-review` znajdziesz listę z punktami, które należy sprawdzić przed stworzeniem każdego merge requestu. To pozwoli Ci wychwycić błędy lub dodatkowe miejsca do usprawnienia przed procesem code review.
