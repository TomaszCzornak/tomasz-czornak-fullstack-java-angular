# Healthcheck

Stwórz branch na bazie gałęzi main: `git checkout -b feature/healthcheck main`

## Opis

Pierwsze zadanie za Tobą, zanim przejdziesz do kolejnych zadań dotyczących autoryzacji warto dodać
endpoint który będzie służył klientom naszego api jako healthcheck.
W tym celu stwórz endpoint, który zwróci informację o stanie api.

## Nice to have

- endpoint dodatkowo sprawdza połączenie z niezbędnymi do funkcjonowania serwera komponentami (na tę chwilę będzie to tylko baza danych)

## Pre code review checklist

W folderze `/tasks/pre-code-review` znajdziesz listę z punktami, które należy sprawdzić przed stworzeniem każdego merge requestu. To pozwoli Ci wychwycić błędy lub dodatkowe miejsca do usprawnienia przed procesem code review.
